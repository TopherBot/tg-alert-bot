# tg‑alert‑bot

A **tiny** Telegram bot that sends scheduled messages (reminders, alerts, birthday wishes, etc.) to a chat.

- **Why this project?**
  - Instant setup – just clone, add your bot token, and push.
  - Fully CI‑enabled (lint, format, test, Docker build).
  - Uses modern Python tooling (uv, ruff, pytest, APScheduler).
  - Ready to ship to a server or a GitHub Actions self‑hosted runner.

## Features
- Config‑driven schedule (`config.yaml`).
- Simple message templating with Jinja2.
- Automatic Docker image build and push (optional).

## Quick start
```bash
# Clone
git clone https://github.com/your‑name/tg-alert-bot.git
cd tg-alert-bot

# Install uv (if you don't have it)
curl -LsSf https://astral.sh/uv/install.sh | sh

# Install dependencies
uv sync

# Create a .env file (see .env.example)
cp .env.example .env
# Edit .env – set TELEGRAM_BOT_TOKEN and TARGET_CHAT_ID

# Run locally
uv run python -m tg_alert_bot
```

## CI/CD
- **Lint & format:** `ruff`
- **Tests:** `pytest` with coverage
- **Docker:** multi‑stage build, pushed by the `release` workflow.
